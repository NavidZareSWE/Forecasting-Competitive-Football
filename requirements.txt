# Install the current release of everything:
#
#     pip install -r requirements.txt
#
# Versions are lower bounds, not pins. The floors are the oldest release that
# provides an API this project actually calls; anything newer is expected to
# work and the latest is preferred. Pinning exact versions was breaking installs
# on Python 3.14, where older pandas has no prebuilt wheel and pip falls back to
# compiling from source.
#
# Reproducibility is handled separately: run_pipeline.py records the exact
# resolved versions into console-outputs/00_environment.txt and writes
# requirements.lock.txt, and Appendix B of the report prints the lock file when
# it exists. That gives an exact record of what produced a given set of results
# without forcing anyone to install those versions.
#
# Python 3.12 or newer. xgboost and lightgbm need OpenMP on macOS
# (brew install libomp); model_zoo.py drops them silently if the import fails.
